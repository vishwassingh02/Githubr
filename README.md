## 🛒 Amazon Homepage Clone

A responsive Amazon Homepage Clone built using HTML5 and CSS3. This project recreates the look and feel of Amazon's homepage while helping developers practice frontend development concepts such as layouts, Flexbox, styling, and responsive design. 

---

## 📌 Features

 - Amazon-inspired navigation bar
 - Search bar with category selection
 - Hero banner section
 - Responsive web design
 - Product category boxes
 - Footer section similar to Amazon
 - Clean and organized UI design

---

## 🛠️ Technologies Used

 - HTML5
 - CSS3
 - Flexbox

---

## How to Run the Project

1. Clone the repository

2. Navigate to the project folder

3. Open index.html in your browser.
